Privacidad

Resumen

Esta web no recoge datos personales. La fecha de nacimiento que escribes se usa solo en tu navegador para calcular las fechas: no se envía a ningún servidor, no se guarda (ni en cookies ni en el almacenamiento del navegador) y no va en la dirección de la página. El archivo de calendario (.ics) también se crea en tu navegador.

Qué no hacemos

  • No usamos cookies ni almacenamiento local.
  • No hay formularios que envíen datos, ni registro, ni boletín.
  • No hay analítica, publicidad ni herramientas de terceros que te sigan.

Alojamiento

La web está alojada en GitHub Pages (GitHub, Inc.). Según su documentación, GitHub registra la dirección IP de quien visita un sitio de GitHub Pages por motivos de seguridad. Más información en la documentación de GitHub Pages y en la declaración de privacidad de GitHub.

Enlaces a otras webs

Si sigues un enlace a una fuente oficial, se aplica la política de privacidad de esa web.

Si usas un enlace «Añadir a Google Calendar», se abre Google Calendar con el título, la fecha y la descripción de esa cita (nunca la fecha de nacimiento). A partir de ahí se aplica la privacidad de Google.

Responsable y contacto

Si algún día se añaden publicidad, afiliados o analítica, esta página y la de cookies se actualizarán antes.
